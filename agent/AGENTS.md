# Python learning repository

This repository is an impedance-focused ML engineering course for an experienced
R data scientist, restarted on 2026-10-05. Neural networks and classical ML are
the main focus; exploratory statistics remain an integrated part of the course.

Before creating, changing, or reviewing any lesson notebook, read and follow
`agent/LEARNING_PLAN.md` in full. It defines the learner profile, curriculum,
notebook format, teaching behavior, file naming, datasets, and progress rules.

Treat requests such as "let's do day 1", "next lesson", or "give me a 60-minute
session" as requests to create the appropriate exercise notebook according to that
plan. Read `agent/PROGRESS.md` as well. Do not solve notebook exercises unless the
learner explicitly asks for a solution. Old material in
`pre_employment_learning/` is history, not the active course.
