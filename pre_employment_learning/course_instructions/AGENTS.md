# Python learning repository

This repository is an adaptive Python course for an experienced R data scientist.

Before creating, changing, or reviewing any lesson notebook, read and follow
`agent/LEARNING_PLAN.md` in full. It defines the learner profile, curriculum,
notebook format, teaching behavior, file naming, datasets, and progress rules.

Treat requests such as "let's do day 1", "next lesson", or "give me a 60-minute
session" as requests to create the appropriate exercise notebook according to that
plan. Do not solve notebook exercises unless the learner explicitly asks for a
solution.
